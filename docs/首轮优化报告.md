## 日常使用变化

1. 在会员管理中新增会员，录入初始卡信息；手机号和卡号不能重复。
2. 充值通过外部收款方式入账。消费明确从账户余额扣款，次数卡可选同时扣次，提交前显示结果。
3. 操作失败保留表单输入；会员/交易提交有防重复确认锁。
4. 归档会员保留交易历史，恢复后可继续使用；归档会员不能交易。
5. 在系统设置中导出完整备份；导入先预览并确认。损坏数据不会自动清空，可导出原始数据保全现场。
6. 报表分别统计充值、消费、退款；余额和卡类型分布为当前快照，不标为营收。

## 复核与仍待改善

独立复核的Important（HTTP兼容）已复现并修复，新增测试从失败到通过。两项Minor已在第二轮（2.1.1）修复，以下保留原始问题记录：
