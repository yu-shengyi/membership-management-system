# 第三轮测试优化说明（2.1.2）

日期：2026-11-13。继续已确认的可靠性与日常界面优化范围，不新增课程业务或后台。

## 测试驱动的修复

1. 普通资料更新原先能够覆盖卡类型，导致次数资产被界面隐藏；现在业务层也保护原卡类型。
2. 普通资料更新能够覆盖最后到访时间；现在该字段由消费产生，资料更新保留历史值。
3. 备份校验接受超过安全整数范围的积分与次数；现在对所有计数使用安全整数校验。
4. 浏览器拒绝本地存储时，恢复设置页会再次抛错、变空白；现在显示读取失败并保持设置页可访问，导出失败也会显示提示。
5. 导入、归档等确认操作在存储失败后抛出未处理异常，确认按钮锁住；现在保留弹层与原数据，恢复存储后允许重试。相同处理用于历史恢复、演示清理和清空确认。

前三项由失败业务测试复现；存储禁用和导入重试先在隔离真实组件环境复现失败，再修复至通过，随后加入真实 Chromium 回归。测试使用独立合成数据，不读取用户会员记录。

## 测试范围

- 23 项业务用例：保留原 19 项业务测试，新增 4 项边界测试；两项旧的源码字符串断言改为真实浏览器行为检查。
- 每种部署路径 11 项浏览器用例，共 22 项：新增与重复手机号、刷新持久化、充值防重、消费失败、存储写入失败、中文筛选、归档恢复、导出导入与取消、损坏数据恢复、存储禁用、演示编辑、手机长表单与导航。
- 根路径和 Pages 子路径分别构建测试，每种路径覆盖 390/820/1440px 下六个页面的横向溢出和截图。
- 本机运行测试、静态检查和构建；真实 Chromium 由 GitHub Linux 环境执行。本机因系统进程/管道限制无法启动浏览器，不将其记录为浏览器通过。
- GitHub 的 browser-* 产物保存截图和追踪，具体通过状态以对应提交的 Actions 结果为准。
