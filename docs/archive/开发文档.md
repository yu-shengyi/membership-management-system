# 会员管理系统 v2.0 - 开发文档

## 🏗️ 项目架构

### 技术选型
- **前端框架**: React 18.3.1
- **开发语言**: TypeScript 5.3.3
- **构建工具**: Vite 8.3.6
- **UI 组件库**: Ant Design 6.7.0
- **状态管理**: Zustand 5.1.0
- **路由管理**: React Router 7.18.5
- **图表库**: Recharts 3.10.1
- **日期处理**: dayjs 1.11.23
- **HTTP 客户端**: axios 1.21.1

### 添加新的 Store

#### 1. 创建 Store 文件
```typescript
// src/store/newStore.ts
import { create } from 'zustand';

interface NewStore {
  data: any[];
  loading: boolean;
  loadData: () => void;
}

export const useNewStore = create<NewStore>((set, get) => ({
  data: [],
  loading: false,

  loadData: () => {
    set({ loading: true });
    // 加载逻辑
    set({ loading: false });
  },
}));
```

#### 2. 在组件中使用
```typescript
import { useNewStore } from '@/store/newStore';

function Component() {
  const { data, loading, loadData } = useNewStore();

  useEffect(() => {
    loadData();
  }, [loadData]);

  return <div>{/* 渲染 */}</div>;
}
```
