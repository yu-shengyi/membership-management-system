# 2.2.0 课程排课与预约

用户选择“先只做排课和预约”，因此本轮交付范围为店员在本地浏览器管理课程、教练/场地排课、容量、会员预约与取消。没有签到、扣费、退款、自助会员登录或后端同步。

## 操作入口

课程页“课程目录”维护可复用课程；“排课与预约”按日期、课程、状态与关键词筛选。课次“查看预约”打开名单，可搜索会员、预约、取消或编辑排课。工作台提供今日课程入口。详情地址包含课次编号，刷新可恢复。

新预约校验卡在上课日期的有效期、冻结/手动过期/归档、同课次重复、撞课与容量。所有预约操作对会员余额、积分、次数、到访时间和交易保持不变。新功能不能用于实际签到或消费结算。

## 历史与恢复

已开始课次不允许预约、编辑或取消。开课前取消课次会级联取消未完成预约，保留全部历史；如果导入的课次包含已完成预约，禁止整课取消以保护历史。

备份格式提升为 2.2.0，旧 2.0.0/2.1.0 缺少新集合时补为空，不改写旧会员、交易与预约。旧预约无课次关联时只读展示。导入旧备份仍是全量替换，不会偷偷拼接当前新课次。请先导出当前备份。

演示清理不会删除课程目录或课次。存储主快照失败不发布部分 UI 数据，表单可重试；历史备份失败单独警告。当前仍适合单操作员使用，不能保证多个标签页并发写入的正确性。
