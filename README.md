# 会员管理系统 2.2.0

本地会员运营工具，包含工作台、会员管理、交易记录、报表、设置、课程排课与预约。数据保存在当前浏览器 LocalStorage 中。

## 开发与验证

使用 Node.js 22.18+ 或 24（本次使用 24.18.0）。在项目目录运行：

    npm ci
    npm run dev
    npm test
    npm run lint
    npm run build
    npm run preview

开发地址默认 http://localhost:5173，预览默认 http://localhost:4173。生产部署使用 dist 目录，并配置所有页面路径回退到 index.html。请通过 Web 服务访问，不直接双击 HTML。

## 当前功能

- 工作台显示在册/正常会员、当前余额、今日消费、临近到期与低次数待办。
- 会员按姓名/手机/编号/卡号、状态、卡类型、归档筛选，支持归档和恢复。
- 新会员可录入初始余额、积分和次数；编辑时账户数值只读。卡类型编辑锁定，避免将次数资产切换隐藏。
- 充值通过外部收款方式增加余额；消费从余额扣款，可为次数卡同时扣除次数。每笔操作统一保存账户和流水。
- 消费拒绝过期、冻结、归档、未生效卡、余额不足与次数不足。到期日当天仍有效。手动标记过期也会阻止消费，续期时需将状态改回正常。
- 充值、消费、退款历史分别统计；当前余额与卡类型分布属于当前快照，不代表历史营收。
- 备份导入先校验和预览，支持 2.0.0 / 2.1.0 / 2.2.0；自动备份保留最近7次，按稳定编号恢复。旧备份恢复会整体替换当前课程与预约，请先导出当前完整备份。
- 旧数据迁移后保留原始键；数据损坏时显示恢复入口，不自动清空。故障恢复的原始导出用于保全数据，不是普通导入格式。
- 演示会员带独立标记，清理仅影响演示会员及其关联记录。
- 课程目录支持默认时长/名额和停用；排课支持教练、场地、容量、日期/状态筛选及冲突检查。
- 店员为会员预约，检查上课日资格、重复、撞课和满额；开课前可取消预约或整个课次，历史记录保留。
- 本轮仅排课预约，不提供签到、扣次或扣余额，所有预约操作均不改变会员资产与交易。工作台显示今日课程和预约人次。

## 课程预约使用

1. 进入“课程管理”，新增课程，填写默认时长、名额和说明。
2. 点击“新增排课”，选择课程，填写未来开始时间、教练和场地；同一教练或场地不能重叠。
3. 点击课次“查看预约”，搜索会员，检查提示后确认预约。不收费，也不冻结次数或余额。
4. 在名单中取消预约可释放名额；取消整个课次会同时取消有效预约。开课后不再允许预约、编辑或取消。
5. 如已有有效预约，排课只允许修改教练、场地和容量。课程目录修改不追溯影响旧课次。

手机可完成同样操作。时间按当前设备的本地时区显示和筛选；使用不同设备恢复备份时，应核对其时区设置。升级前没有课次关联的预约在“历史预约”中只读保留。

## 技术栈

React 19、Ant Design 6、React Router 7、Zustand 5、Recharts 3、TypeScript 7、Vite 8。具体版本以 package-lock.json 为准。各页面按需加载。

## 数据与使用边界

请定期在设置中导出完整备份。浏览器数据不会自动跨设备同步，尚无后端、员工登录权限或多门店支持。多个标签页会同步已提交数据，但同时写入仍可能发生覆盖；当前版本适合单操作员使用。

升级后发现旧数据格式异常时，请导出原始数据保留现场，再导入合法备份；不要直接清理浏览器数据。历史流水保留原记录，新增消费显示“账户余额”和实际扣次，旧流水未记录次数时显示“未记录”。

开发文档中的早期功能和版本描述属于历史记录；当前行为以本文、TESTING.md 和 docs/课程预约开发说明.md 为准。

## GitHub发布

推送main后自动运行测试、静态检查和构建，再发布dist。Pages配置和Docker启动见DEPLOYMENT.md。仓库保留源码，不提交编译产物。旧版本可从Git历史恢复。

## 自动测试

业务回归运行 `npm test`，真实 Chromium 测试运行 `npm run test:browser`（需 Python、Playwright 与已启动的生产预览）。环境准备、测试范围、截图和追踪说明见 TESTING.md。GitHub 会测试根路径与 Pages 子路径，两者通过后才部署。
