# 📤 上传到 GitHub 详细步骤

## 第一步：安装 Git ⚠️

**如果你还没有安装 Git，必须先安装：**

1. 访问：https://git-scm.com/download/win
2. 点击页面中的下载链接
3. 下载完成后，运行安装程序
4. **安装时全部使用默认设置，一直点 "Next"**
5. 安装完成后，**重启电脑**（非常重要！）

---

## 第二步：在 GitHub 创建仓库

1. **登录 GitHub**（https://github.com）
   - 如果没有账号，先注册一个

2. **创建新仓库**
   - 点击右上角的 "+" 号
   - 选择 "New repository"

3. **填写仓库信息**
   - Repository name: `membership-system`（或你喜欢的名字）
   - Description: `会员管理系统`
   - 选择 `Public`（公开）
   - ⚠️ **不要勾选任何选项**（不要添加 README、.gitignore、License）
   - 点击 "Create repository"

4. **复制仓库地址**
   - 在新页面中，找到类似这样的地址：
   ```
   https://github.com/你的用户名/membership-system.git
   ```
   - **复制这个地址**（待会要用）

---

## 第三步：上传项目

1. **找到项目文件夹**
   ```
   C:\Users\10099\Desktop\会员管理系统
   ```

2. **双击运行 `上传到GitHub.bat`**

3. **按提示操作**：
   - 当提示输入仓库地址时
   - **粘贴**你在第二步复制的地址
   - 按回车

4. **如果要求登录**：
   - 会弹出浏览器登录窗口
   - 登录你的 GitHub 账号
   - 授权访问

5. **等待上传完成**
   - 看到 "上传成功！" 就完成了

---

## 第四步：验证上传

1. 刷新你的 GitHub 仓库页面
2. 应该能看到所有文件
3. README.md 会自动显示在页面下方

---

## ❓ 常见问题

### Q1: 提示 "未安装 Git"
**解决：** 按照第一步安装 Git，然后**重启电脑**

### Q2: 提示 "fatal: not a git repository"
**解决：** 确保从**项目根目录**运行脚本（不是 scripts 目录）

### Q3: 推送失败
**原因：**
- 网络问题
- 仓库地址错误
- 需要登录

**解决：**
1. 检查网络连接
2. 确认仓库地址正确
3. 在浏览器中登录 GitHub

### Q4: 如何更新已上传的代码？
**答：** 修改文件后，打开命令行运行：
```bash
cd C:\Users\10099\Desktop\会员管理系统
git add .
git commit -m "更新说明"
git push
```
